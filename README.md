# Rafter Cat's Looking Glass

A mod previewer and information bank for Penumbra (Dalamud plugin).
Find that one shirt without trying on fifty mods.

- Searchable list of every mod in your Penumbra folder, in your own folder order
- Scroll through with the arrow keys
- Shows where each mod sits in Penumbra, with a Copy name button
- `/lookingglass` or `/lglass` opens it

It only reads your Penumbra mod list and mod info. It doesn't change your mods, and nothing goes online.

Install link (Dalamud > Settings > Experimental > Custom Plugin Repositories):
`https://raw.githubusercontent.com/The-Kinship/looking-glass/main/repo.json`
